# CHECKLIST DE REVISAO FINAL DA PECA

## 1) Estrutura
- [ ] Enderecamento correto
- [ ] Qualificacao completa e coerente
- [ ] Secoes obrigatorias presentes
- [ ] Ordem logica preservada (preliminares -> merito -> pedidos)

## 2) Coerencia fatico-probatoria
- [ ] Cada alegacao relevante aponta documento
- [ ] Datas e valores estao coerentes em todo o texto
- [ ] Nao ha contradicoes internas
- [ ] Nao ha afirmacao sem lastro nos autos

## 3) Fundamentacao
- [ ] Fundamentos legais adequados ao pedido
- [ ] Teses principal e subsidiarias bem delimitadas
- [ ] Pedido recursal (se houver) corresponde ao vicio apontado
- [ ] Linguagem tecnica, objetiva e clara

## 4) Pedidos e requerimentos
- [ ] Pedidos principais e subsidiarios estao completos
- [ ] Provas requeridas estao especificadas
- [ ] Custas/honorarios foram tratados quando cabivel
- [ ] Valor da causa indicado quando aplicavel

## 5) Conformidade de fontes
- [ ] Nenhuma citacao/precedente foi inventado
- [ ] Somente material enviado no caso foi utilizado
- [ ] Lacunas foram convertidas em pendencias explicitas

## 6) Entrega
- [ ] Nome do arquivo segue padrao <tipo_peca>_<YYYY-MM-DD>.md
- [ ] Arquivo salvo em casos/<id-do-caso>/saida/
- [ ] Bloco Pendencias para completar incluido ao final
- [ ] Versao pronta para revisao humana final

## 7) Quando for analise contratual
- [ ] Clausulas foram mencionadas de forma expressa ao longo do texto
- [ ] Existe quadro de prioridades sem repeticao excessiva na conclusao
- [ ] O texto esta formal, claro e adequado para apresentacao ao cliente
- [ ] Se houver template DOCX fornecido, a versao final respeita o modelo original
